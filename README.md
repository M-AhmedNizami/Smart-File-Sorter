# Smart File Sorter

A Python GUI tool designed to scan analyze and safely organize personal files with built in rollback capabilities.


> *Note: This project is currently under construction.*


### How to Run


1. Clone the repository
```bash
git clone https://github.com/M-AhmedNizami/Smart-File-Sorter.git
cd Smart-File-Sorter
```


2. Run the application
```bash
python main.py
```
